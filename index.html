01 — 项目

从纯向量 RAG 到图谱+多模态，把"答不上"变成"答得准"。

/ 01

ScholarGraph↗

Academic Knowledge Graph QA

用知识图谱的多跳推理，回答纯向量 RAG 答不了的跨文档关系问题——比如"某论文的作者还发表过什么"。向量检索负责"召回相似"，图谱一跳负责"召回相关"。

向量 + 图谱混合检索 · 自建 100 条评测集，命中率 62% → 85%+

Python NetworkX ChromaDB Streamlit
Demo · 学术知识图谱 GraphRAG
/ 02

Knowledge Agent↗

RAG-Powered Multi-turn Agent

LangGraph 状态机驱动的多轮问答 Agent，带会话记忆、工具调用与人工确认节点。覆盖 RAG 全链路：分块实验 → 检索 → 重排 → RAGAS 评估，最后用 FastAPI 暴露成可调用的服务。

完整产品化链路 · 分块策略 + 重排模型都对最终召回有显著影响

LangGraph RAG FastAPI RAGAS
Demo · 个人知识库 Agent
/ 03

Paper Vision Agent↗

Multimodal Figure QA over Knowledge Graph

视觉大模型结构化解析论文图表，联动知识图谱做答案佐证，支持多轮追问。覆盖论文里"看图说话"这一类纯文本 RAG 完全无能为力的场景。

GLM-4V 图文解析 · 答案回链到图谱节点

GLM-4V 多模态 GraphRAG
Demo · 论文图表多模态问答
/ 04

2048 对战版↗

Turn-based Battle 2048 · Vibe Coding

把单人 2048 改造成双人回合制对战：双方各持 4×4 棋盘轮流出手，先合成 2048、或把对手逼入死局者获胜。用「验收标准先行 + 小步提交」的指令流程驱动 AI 生成，规则正确性全部由可判定的回归用例兜底。

1 小时交付可玩 Demo · 指令迭代 7 轮（含 2 个 Bad Case 修复）· 35 条逻辑回归用例通过

HTML5 JavaScript Vibe Coding Spec-driven
